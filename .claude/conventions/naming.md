# File Layout & Naming Conventions

* PascalCase for component folders and files (src/components/Button/Button.tsx).
* camelCase for utilities, hooks, and helpers (src/hooks/useFocusTrap.ts).
* kebab-case for styles, tokens, and asset files (src/styles/tokens.css).
* Group each component into its own directory containing implementation, styles, unit tests, and documentation/stories.
